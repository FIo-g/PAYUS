08 / Empty States

빈 상태 패턴

실수가 아니라 의도된 화면처럼
⌕
근처 가맹점이 없어요

위치를 다시 확인하거나 검색 반경을 넓혀 보세요. 새로운 제휴는 매주 추가돼요.

EMPTY
아직 결제 내역이 없어요

첫 결제 시 +5% 추가 캐시백을 드려요. 가까운 가맹점부터 둘러볼까요?

!
잠시 연결이 끊겼어요

결제는 안전하게 보류된 상태예요. 잠시 후 다시 시도해 주세요.

ERR_NETWORK_TIMEOUT · 0x4081
EMPTY STATE 원칙
  • 상태 이름은 짧고 사람말처럼
  • 다음 행동을 명확히 제안
  • 에러는 사용자 책임으로 돌리지 않음
  • 일러스트 대신 토큰 도형으로 톤 유지
  • 오류 코드는 caption으로 작게
  • 첫 사용 컨텍스트에는 인센티브를 명시
09 / Handoff

개발자 핸드오프

파일 구조

// project root
tailwind.config.js    // 모든 토큰 (color · spacing · radius · type · motion)
tokens.css            // CSS 변수 + .dark 오버라이드
components/
  Button.jsx          // variant × size × loading
  Input.jsx           // label · help · error · password toggle
  Badge.jsx           // cashback × status × chips
  Card.jsx            // MerchantCard
  BottomSheet.jsx     // modal · esc · fixed | container 모드

App 설정

// tailwind.config.js (your app)
const sejong = require('./tailwind.config.js');
module.exports = {
  presets: [sejong],
  content: ['./src/**/*.{js,jsx,ts,tsx}'],
  darkMode: 'class',
};

// app entry
import './tokens.css';
import './tailwind.css';

// usage
<Button variant="primary" size="lg" block>
  8,500원 결제하기
</Button>
